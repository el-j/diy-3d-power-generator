# VAWT Blade Comparison — WindPower-3D

> Five interchangeable vertical-axis wind turbine blade designs for the Helix Wind-Generator tower stack.
> All designs share the unified Vielzahn spline coupling and print within the Bambu P1S 256 mm bed.

---

## Overview: Hot-Swappable Blade Assemblies

The WindPower-3D tower is built as a stack of identical stages. Each stage is 240 mm tall, carries one blade assembly, and connects to the next via the unified Vielzahn (multi-tooth spline) coupling. Because the coupling geometry is identical across all five blade types, a complete blade swap requires only removing the connector cap, sliding out the old blade set, and pressing in the new one — no shaft modification, no re-drilling, no re-wiring.

This modularity lets you:
- Match blade aerodynamics to your local wind regime without rebuilding the tower
- Mix blade types across stages (e.g., a Savonius stage at the bottom for low-wind start-up, Gorlov stages above for efficiency)
- Test and compare blade types on the same physical tower over time

All five designs described in this document are parametrically defined in `shared/parameters.json` under `tower` and `tower_variants`, and are generated by scripts in `src/leaf/`.

## Unified Coupling System

Every blade design uses the same mechanical interface. These dimensions are locked and must never be changed independently per blade type — they are defined once in `global` and `tower` sections of `shared/parameters.json`.

| Parameter | Value | Source key |
|-----------|-------|------------|
| Spline profile | Vielzahn (multi-tooth) | `global.vielzahn_zaehne` |
| Number of teeth | 12 | `global.vielzahn_zaehne` |
| Indexing step | 30° per tooth | derived |
| Outer radius | 9.0 mm | `global.vielzahn_r_out` |
| Inner radius | 7.8 mm | `global.vielzahn_r_in` |
| Orientation offset | +15° (aligns teeth to shaft corners) | hardcoded in `make_vielzahn_prism()` |
| Square shaft | 10 × 10 mm + 0.5 mm tolerance | `global.achse_kantenlaenge` + `global.toleranz` |
| Stage height | 240 mm | `tower.hohe` |
| Blade radius | 66 mm (132 mm rotor diameter) | `tower.blatt_radius` |
| Connector cap height | 8 mm | `tower.kappen_dicke` |
| Groove depth (snap fit) | 3 mm | `tower.rillen_tiefe` |

The +15° orientation offset is critical: it rotates the spline teeth so that the thick tooth flanks land exactly on the 45° diagonal corners of the square shaft hole, distributing torque evenly and preventing stress concentrations.

## Blade Designs

### 1. Helix (Savonius Coreless Helical) — `TWR-LEAF-01`

The default blade of this project. A single blade surface twisted 90° from bottom to top using a lofted helix through 60 interpolation steps. Because the blade is never absent from any azimuth angle (the 90° twist gives continuous coverage), a single blade per stage suffices.

| Specification | Value |
|---------------|-------|
| Principle | Hybrid drag/lift |
| Blades per stage | 1 |
| Wall thickness | 2.4 mm |
| Twist | 90° (bottom to top) |
| Loft steps | 60 |
| Tip Speed Ratio (TSR) | 1.0–1.5 |
| Power coefficient (Cp) | ~18% |
| Self-starting | Yes |

**Key parts:** `Coreless_Helix_Fluegel`, `Mittel_Verbinder_Skelett_FLACH`, `Zwischen_Vielzahn_Plug`, `Start_Scheibe_FLACH`

**Best for:** Variable or gusty wind, urban rooftops, sites with frequent wind direction changes. The lowest cut-in wind speed of the lift-assisting designs.

**Print settings:** PETG, 0.6 mm nozzle, 20% infill, supports required for overhanging loft surface.

---

### 2. Savonius Straight — `TWR-STR-01`

The classical Savonius bucket rotor. Two opposing semi-circular cups extruded vertically with no twist. The advancing cup captures drag force; the retreating cup is partially sheltered by the advancing one. Simple geometry, maximum printability, highest starting torque.

| Specification | Value |
|---------------|-------|
| Principle | Pure drag (Savonius bucket) |
| Blades per stage | 2 (180° opposing) |
| Wall thickness | 2.4 mm |
| S-offset | 12 mm |
| Twist | 0° |
| TSR | ~0.8–1.0 |
| Cp | ~14% |
| Self-starting | Yes — highest starting torque of all five types |

**Best for:** Very low wind speeds (below 3 m/s cut-in), mechanical loads requiring high torque (water pumps, grain mills), sites where turbine must never stall.

**Print settings:** PETG, 0.6 mm nozzle, 20% infill, no supports needed (straight extrusion).

---

### 3. Darrieus H-Rotor — `TWR-DAR-01`

A straight-bladed Darrieus rotor (H-frame). Three symmetric airfoil blades at 120° spacing generate lift as they orbit the shaft. The airfoil cross-section approximates a NACA profile: a 4 mm half-cylinder nose, a 2.2 mm half-cylinder tail, and a 15.4 × 4 mm body offset 1.2 mm toward the leading edge. Two horizontal struts per blade at 15% and 85% height carry the blade loads to the central hub.

| Specification | Value |
|---------------|-------|
| Principle | Pure lift (airfoil) |
| Blades per stage | 3 (120° spacing) |
| Chord | 20 mm |
| Thickness | 4 mm |
| Strut diameter | 4 mm |
| Hub radius | 12 mm |
| Twist | 0° (straight H-frame) |
| TSR | 3.0–4.0 |
| Cp | ~28% |
| Self-starting | Poor — needs initial push or motor-start assist |

**Best for:** Sites with consistent moderate-to-high wind (above 5 m/s), applications where efficiency is the primary goal and self-starting is not required.

**Print settings:** PLA-CF, 0.4 mm nozzle (required for airfoil accuracy), 100% infill on struts, 40% infill on blade body.

---

### 4. Gorlov Helical — `TWR-GOR-01`

A helical Darrieus rotor: the same lift-generating airfoil principle as the H-rotor, but with three blades each twisted 120° over the full stage height. The helical offset means that at any instant, at least one blade is in a favorable lift position — torque ripple is dramatically reduced compared to the straight Darrieus, and the rotor is self-starting due to the asymmetric torque distribution at rest.

| Specification | Value |
|---------------|-------|
| Principle | Lift-drag hybrid (helical Darrieus) |
| Blades per stage | 3 (120° base spacing) |
| Chord | 16 mm |
| Thickness | 3.4 mm (biconvex symmetric) |
| Twist | 120° per stage height |
| Loft steps | 48 |
| TSR | 2.0–3.0 |
| Cp | ~32% |
| Self-starting | Yes |

**Best for:** Consistent wind regimes, applications requiring maximum efficiency and smooth power delivery. The highest Cp of all five designs.

**Print settings:** CF-Nylon or PLA-CF, 0.4 mm nozzle, 40% infill, no supports (helical loft is self-supporting).

---

### 5. Lenz2 — `TWR-LEN-01`

An asymmetric cup rotor that combines Savonius drag capture with leading-edge vortex lift. The outer cup spans 210° of arc; the inner surface is the same arc scaled to 62% and offset inward by the wall thickness. This geometry creates a deep cup that captures the direct drag impulse while the sharp leading edge generates a vortex that produces additional lift — a similar mechanism to delta-wing aerodynamics at high angle of attack.

| Specification | Value |
|---------------|-------|
| Principle | Drag with vortex-assist lift (Lenz2/Magnus hybrid) |
| Blades per stage | 3 (120° spacing) |
| Cup arc | 210° |
| Inner surface scale | 0.62× |
| Wall thickness | 2.4 mm |
| Twist | 0° |
| TSR | 1.2–1.8 |
| Cp | ~22% |
| Self-starting | Yes |

**Best for:** Urban or suburban environments with turbulent, direction-changing wind. Better efficiency than pure Savonius while retaining reliable self-starting. A practical compromise between the Helix and the Gorlov.

**Print settings:** PLA-CF, 0.6 mm nozzle, 30–40% infill, no supports needed.

## Selection Guide

Choose your blade type based on your highest-priority constraint:

**Maximum starting torque / mechanical load (pump, mill):**
Use **Savonius Straight**. Nothing starts more reliably or delivers more torque at low RPM. Accept the lower Cp as the cost of robustness.

**Lowest possible cut-in wind speed:**
Use **Helix** or **Savonius Straight**. Both self-start below 2 m/s in light breeze. The Helix adds modest lift assist above that threshold.

**Maximum electrical efficiency:**
Use **Gorlov Helical**. At ~32% Cp it approaches the practical ceiling for a VAWT, and unlike the Darrieus H-Rotor it self-starts reliably.

**Urban or rooftop installation (turbulent, gusty, direction-variable wind):**
Use **Helix** or **Lenz2**. The Helix handles direction changes best; the Lenz2 offers better average Cp in turbulent conditions where the wind maintains a rough dominant direction.

**Consistent moderate-to-high wind, efficiency critical, motor-start available:**
Use **Darrieus H-Rotor**. Its pure lift principle gives the most predictable power curve once above cut-in speed, and the straight extrusion keeps print tolerances tight on the airfoil.

**General-purpose / unknown site:**
Start with the **Helix** (default assembly). It is the design this project was built around, has the most tested connector geometry, and performs acceptably across the widest range of conditions.

## Aerodynamic Concepts

### Tip Speed Ratio (TSR)

TSR is the ratio of blade tip velocity to wind velocity: `TSR = (blade tip speed) / (wind speed)`. A TSR of 1.0 means the tip moves at the same speed as the incoming wind. Drag-based rotors operate efficiently at low TSR (0.8–1.5) because the drag force diminishes as the blade accelerates toward wind speed. Lift-based rotors need the blade to move faster than the wind (TSR 2–4) to maintain a favorable angle of attack on the airfoil. TSR directly determines whether a given rotor design is well-matched to a generator's load torque curve.

### Power Coefficient (Cp)

Cp is the fraction of available wind power that the rotor converts to shaft power: `Cp = P_shaft / P_wind`. The Betz limit (59.3%) is the theoretical maximum for any wind turbine — no rotor can extract more than this fraction of the kinetic energy from a stream of air without bringing it to a complete stop. In practice, VAWTs reach 20–35% Cp due to tip losses, blade wake interference, and mechanical friction. Horizontal-axis turbines can reach ~45% Cp but are not self-starting and require active yaw control.

### Self-Starting

A rotor is self-starting if it can accelerate from rest to operational speed without external assistance. Drag-based rotors (Savonius, Lenz2) self-start because drag force acts on the stationary blade immediately — the cup facing into the wind experiences higher drag than the cup facing away. Lift-based rotors (Darrieus) do not self-start easily: airfoil lift requires a minimum angle of attack relative to the apparent wind, which only develops once the blade is already moving at a significant fraction of the target TSR. Helical variants (Gorlov) partially solve this by ensuring that at least one blade always has an asymmetric position that creates a net torque at rest.

### Torque Ripple and Helical Designs

A straight-bladed rotor generates pulsing torque: as each blade passes through the high-drag/high-lift azimuth angle, shaft torque spikes, then drops as the blade moves to the unfavorable position. With 2 blades, torque ripple frequency is `2 × RPM`; with 3 blades, `3 × RPM`. This ripple stresses the drivetrain, creates vibration, and causes voltage ripple in the generator output. Helical designs (Helix with 90° twist, Gorlov with 120° twist) spread the blade's contribution across all azimuth angles simultaneously: the bottom of the blade is always at a different position than the top. The result is a nearly constant torque delivery regardless of RPM — quieter operation, lower bearing stress, and cleaner electrical output with less rectification filtering required.

## Glossary

| Term | Definition |
|------|------------|
| VAWT | Vertical-Axis Wind Turbine — shaft is vertical, works regardless of wind direction |
| TSR | Tip Speed Ratio — blade tip velocity divided by wind velocity |
| Cp | Power coefficient — fraction of wind power extracted by the rotor |
| Betz limit | 59.3% — theoretical maximum Cp for any wind turbine |
| Savonius | Drag-type VAWT using opposing cups; high torque, low efficiency |
| Darrieus | Lift-type VAWT using airfoils; high efficiency, poor self-starting |
| Gorlov | Helical Darrieus variant; smoothed torque, self-starting |
| Lenz2 | Asymmetric cup with vortex-lift assist; intermediate drag/lift |
| Vielzahn | Multi-tooth spline coupling used throughout this project |
| TWR-LEAF-01 | Part ID for the Helix blade assembly |
| TWR-STR-01 | Part ID for the Savonius Straight blade assembly |
| TWR-DAR-01 | Part ID for the Darrieus H-Rotor blade assembly |
| TWR-GOR-01 | Part ID for the Gorlov Helical blade assembly |
| TWR-LEN-01 | Part ID for the Lenz2 blade assembly |
| Torque ripple | Cyclic variation in shaft torque as blades rotate through their azimuth positions |
| Cut-in speed | Minimum wind speed at which the rotor begins generating useful power |
| Loft | FreeCAD operation that interpolates a 3D surface between a series of 2D cross-sections |
